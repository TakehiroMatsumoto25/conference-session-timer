How to use

Set the duration and bell times in Settings. Enter either the time remaining or the time from the start. Check the sound with Test Bell, then select Save.

Space start/pause · R reset · F toggle fullscreen · S open settings · Esc close settings

Settings で発表時間とベルを設定します。ベルは残り時間か開始からの時間で入力できます。Test Bell で試聴し、Save で保存します。

Space 開始・一時停止 ／ R リセット ／ F 全画面切り替え ／ S 設定を開く ／ Esc 設定を閉じる

Timing Accuracy

The timer calculates the time remaining using performance.now(), a browser clock that runs independently of your computer’s time settings. Each screen update uses the latest elapsed time.

Paused time is excluded. The display rounds time remaining up and overtime down to whole seconds.

The timer detects when the remaining time reaches or passes a bell’s set time. Switching tabs or putting the computer to sleep can delay screen updates and bells. Keep this tab visible and the computer awake during a session.

残り時間は、PCの時刻変更から独立したブラウザの時計 performance.now() で測った経過時間から計算します。画面の更新が遅れても、その遅れは計測に積み重なりません。

一時停止中の時間は計測から除きます。表示は残り時間を秒単位で切り上げ、超過時間を切り捨てます。

ベルは設定した残り時間を通過したことを検出して鳴らします。別のタブに切り替えたり、PCがスリープしたりすると、表示やベルが遅れることがあります。本番中はこのタブを表示し、PCをスリープさせないでください。
